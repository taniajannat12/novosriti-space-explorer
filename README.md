
# 🌙 Lunara — Abandoned but Not Forgotten
Live Link: https://novosriti-space-explorer.vercel.app/
**Lunara** is an interactive, child-friendly space exploration website inspired by NASA Space Apps Challenge 2026.

Users join **Mira**, a student guide, on a journey from Earth to the Moon to explore **Surveyor 3**, learn about NASA's *“Abandoned but Not Forgotten”* challenge, collect clues, and complete an interactive quiz before returning to Earth.

## ✨ Features

* 🚀 Interactive Earth-to-Moon journey
* 👩‍🚀 Mira as a friendly educational guide
* 🌙 Surveyor 3 exploration
* 🔎 Interactive clues and learning
* 🧠 Educational quiz with score
* 🔊 Voice narration and sound effects
* 🌍 Return journey to Earth
* 🎨 Child-friendly space-themed UI

## 🛠️ Tech Stack

* Next.js
* React
* JavaScript
* CSS

## 🎯 Goal

To make space science and NASA missions easier and more enjoyable for children through **storytelling, exploration, and gamified learning**.
